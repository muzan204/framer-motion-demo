# ⚙️ Instalação

## 📥 Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/framer-motion-demo.git
```

---

## 📦 Entre na pasta do projeto

```bash
cd framer-motion-demo
```

---

## 🚀 Instale as dependências

```bash
npm install
```

---

## ▶️ Execute o projeto

```bash
npm start
```
